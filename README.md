# Customer Support Ticket Priority Prediction & Automation

## 📌 Project Overview
This project aims to build an intelligent, automated customer support system using Salesforce and Agentforce AI. It reduces manual effort by analyzing incoming support tickets, predicting their priority (High, Medium, Low) based on the issue description, and automatically routing them to the appropriate support agents.

## 🎯 Business Objective
- Reduce Response Time: Automatically assign critical issues to senior agents.
- Improve Customer Satisfaction: Ensure urgent tickets are addressed immediately.
- Minimize Manual Effort: Eliminate the need for manual ticket triaging.
- Manager Visibility: Provide dashboards to track agent workload and ticket status.

## 🛠️ Tech Stack & Salesforce Components
- CRM: Salesforce (Service Cloud)
- AI/Automation: Agentforce AI, Salesforce Flow Builder
- Data Model: Custom Objects (Ticket), Standard Objects (Case, User, Task)
- Security: Role-Based Access Control (Profiles & Permission Sets)

## 🏗️ System Architecture (Planned)
1. Ticket Creation: Customer submits a ticket via Web/Email.
2. AI Analysis: Agentforce reads the description for keywords (e.g., "urgent", "failure").
3. Priority Assignment: AI sets the priority as High, Medium, or Low.
4. Auto-Routing: Salesforce Flow assigns High-priority tickets to senior agents.
5. Task Creation: Auto-generates tasks for immediate attention.
6. Dashboard: Managers monitor SLA and agent workload.
